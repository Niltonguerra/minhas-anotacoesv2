## 1. O que o edital realmente cobra

O edital atual divide Conhecimentos Específicos de Desenvolvimento de Software em **7 grandes blocos**:

1. Engenharia de software
2. POO em C#, Java, PHP ou similares
3. Estruturas de dados e algoritmos
4. Desenvolvimento web/desktop/APIs
5. Banco de dados aplicado
6. Testes de software e manutenção
7. Documentação e versionamento

Isso está explicitamente no edital.
