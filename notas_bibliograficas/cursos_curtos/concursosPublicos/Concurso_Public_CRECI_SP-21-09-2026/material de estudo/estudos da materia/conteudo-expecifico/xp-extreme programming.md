# Explicação dos tópicos:
### O que é

É uma das metodologias ágeis, assim como Scrum e Kanban. O foco é entregar software de qualidade em ciclos curtos, com práticas técnicas bem definidas.

---

### Práticas principais que a banca cobra

- **Programação em par** — dois desenvolvedores no mesmo código simultaneamente
- **TDD (Test Driven Development)** — escreve o teste antes do código
- **Integração contínua** — código integrado e testado frequentemente
- **Refatoração** — melhorar o código sem mudar o comportamento
- **Releases curtos** — entregas pequenas e frequentes
- **Cliente presente** — cliente participa ativamente do desenvolvimento
- **Código coletivo** — qualquer desenvolvedor pode mexer em qualquer parte do código

---

### Diferença rápida entre as ágeis

|Metodologia|Foco principal|
|---|---|
|**Scrum**|Organização do processo — sprints, papéis, cerimônias|
|**Kanban**|Fluxo visual de tarefas, limite de trabalho em progresso|
|**XP**|Práticas técnicas de desenvolvimento|
