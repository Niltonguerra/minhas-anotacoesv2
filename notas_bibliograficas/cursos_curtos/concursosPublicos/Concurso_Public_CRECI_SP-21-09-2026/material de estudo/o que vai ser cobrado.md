## 1. Como será a prova

Para **Analista de TI**, a prova objetiva terá **60 questões**, distribuídas assim:

|Disciplina|Questões|
|---|---|
|Língua Portuguesa|10|
|Matemática e Raciocínio Lógico|10|
|Inglês Técnico|10|
|**Conhecimentos Específicos**|**30**|
|**Total**|**60**|

A duração será de **4 horas**, já incluindo o tempo da prova discursiva. Cada questão objetiva terá **5 alternativas**, com apenas uma correta.

Além disso, haverá **2 questões dissertativas**. Para Desenvolvimento de Software, serão corrigidas as provas discursivas dos **50 candidatos mais bem classificados na objetiva**, considerando também os empates na última posição.

Isso é importante: **não basta estudar para marcar alternativas; você também precisa conseguir explicar tecnicamente os assuntos.**

# 2. Conhecimentos específicos — Desenvolvimento de Software

Essa é a parte que eu colocaria como **prioridade máxima**, porque são 30 das 60 questões.

O edital divide o conteúdo em seis grandes áreas:

### 1. Engenharia de Software

Você precisa estudar:

- Conceitos de Engenharia de Software
- Metodologia **Cascata**
- Metodologias **Ágeis**
- Levantamento de requisitos
- Análise de sistemas
- Modelagem de sistemas

Aqui eu estudaria especialmente as diferenças entre **Cascata × Ágil**, requisitos funcionais/não funcionais e conceitos básicos de análise/modelagem.

---

### 2. Programação Orientada a Objetos

O edital especifica:

- **C#**
- **Java**
- **PHP**
- ou linguagens similares

O foco é **programação orientada a objetos**.

Eu estudaria principalmente:

- Classes e objetos
- Atributos e métodos
- Encapsulamento
- Herança
- Polimorfismo
- Abstração
- Interfaces
- Sobrecarga
- Sobrescrita
- Modificadores de acesso
- Composição/agregação

Como você já trabalha com TypeScript/Java e tem contato com desenvolvimento, essa provavelmente será uma área relativamente confortável para você.

### 3. Estruturas de Dados e Algoritmos

- **Listas**
- **Pilhas**
- **Filas**
- **Árvores**
- **Grafos**

Aqui eu daria bastante atenção.

Principalmente:

**Estruturas**

- Array

**Algoritmos**

- Busca linear
- Busca binária

E eu estudaria também **complexidade de algoritmos / Big O**, mesmo que o edital não cite expressamente "Big O". É um assunto diretamente relacionado a algoritmos, mas aqui faço uma distinção: **Big O não está escrito literalmente no edital**, portanto não dá para afirmar que será cobrado.
