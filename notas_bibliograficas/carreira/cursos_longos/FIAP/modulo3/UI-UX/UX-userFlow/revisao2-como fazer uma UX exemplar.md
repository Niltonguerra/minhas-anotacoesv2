# Explicação dos tópicos:
## o que precisa ter para ter um UX exemplar:
- usabilidade
	- fácil de usar
- acessibilidade
	- deve ser acessível para deficientes, idosos e etc
	- deve ser acessível para todos
- utilidade
	- deve ser útil, kkkkk
- desempenho
	- não deve travar o sistema
	- deve funcionar direto
- desejabilidade
	- deve ser bonito
	- deve ser desejável
- relevância
	- deve ser relevante para o usuário
	- usar a linguagem adequada para o usuário
- confiança e credibilidade
	-  o produto deve transmitir confiabilidade
- engajamento
	- deve incentivar os usuários a voltarem para o seu produto
	- incentivar o usuário a se cadastrar


## o que define o sucesso de um produto é como o seu publico alvo se sente com relação ao produto
- e como faz para saber como o público alvo se sente com relação ao meu produto?
	-  pode se saber mediante essas perguntas:
		- as pessoas usuárias conseguem utilizar o produto de forma eficiente e sem dificuldades?
		- o produto atende ás necessidades e expectativas das pessoas usuárias?
		- as pessoas usuárias se sentem satisfeitos e felizes ao usar o produto?
		- o produto proporciona uma experiência agradável e memorável para as pessoas usuárias?
			- ex: Disney
