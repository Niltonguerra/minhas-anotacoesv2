# Explicação dos tópicos:
## porque ux é bom em um projeto?
- facilidade de manutenção do sistema
	- reduz  o retrabalho
	- reduz os erros
- facilidade de implementar novos recursos
	- velocidade no desenvolvimento
	- facilita o foco no núcleo do produto(core business)
- criação de valor
	- maior ROI
	- e todos os pontos citados aqui: [[revisao2-como fazer uma UX exemplar]]


## Design Thinking
- é um processo interativo
- serve para permitir as pessoas compreenderem a necessidade e problemas dos usuários,   questionar suposições, redefinir problemas, desenvolver soluções.

processo do design thinking
![[Pasted image 20260521125419.png]]
- três fases macros:
	- entender
	- explorar 
	- materializar

### explicação das fases
- entender
	- empatia
		- entender o problema
		- através de pesquisas com os usuários
	- definição
		- faz a declaração das constatações
		- cria a persona
- explorar 
	- idealização
		- cria ideias para o produto
		- brainstorm
	- prototipagem
		- cria o protótipo do produto
		- tudo bem errar aqui
		- deve criar varias versões do produto 
			- versões baratas do produto
		- fazer testes
			- insider
			- testes internos
		- seria a versão alfa
- materializar
	- teste
		- testar o que as pessoas acham do projeto
		- testes a/b
		- testar se o produto realmente resolve o problema
		- seria aquele lançamento controlado
		- seria a versão Release Candidate
	- implementação
		- lançar o produto
		- acompanhar o que as pessoas estão achando
		- desenvolver a campanha de lançamento
