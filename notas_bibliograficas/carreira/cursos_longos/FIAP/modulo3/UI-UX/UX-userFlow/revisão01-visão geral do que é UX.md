# Explicação dos tópicos:
o ux é a experiencia completa do usuário mediante o serviço prestado
- isso envolve:
	- psicologia
		- a maneira como faz o cliente se sentir
	- arte
		- a forma como aparece
	- ciência
		- a forma como cientifica como funciona


###### UX (user experience) === experiencia do usuário === experiência de quem usa

		- qual é o produto? quem está utilizando este produto? por que estão utilizando?

## principais sub áreas de UX:
![[Pasted image 20260521112037.png]]
- arquitetura de informação
	- tem origem da biblioteconomia
	- é uma forma de organizar as coisas para que as pessoas tenham mais facilidade para encontrar as coisas
	- exemplo de uso: menus de sites

- design de interação
	- é a forma como o sistema responde a interação do usuário
	- e o quanto de informação é mostrado para o usuário em cada parte da tela
	- é a forma de organizar as interações do usuário em um "caso de uso"
	- ex: a jornada de interação de um usuário em fazer uma lista de exercícios

- taxonomia
	- é a forma de organizar as categorias
	- e a escolha da linguagem mais adequada para se comunicar como o seu publico
	- ex: eletrodomésticos ->refrigeradores -> geladeira

- Estratégia de design
	-  definir os propósitos do produto
	- como o produto se desenvolve ao longo do tempo
	- quem é o publico alvo do produto
	- quais são os objetivos do negócio e como eles serão alcançados
	- definir a persona
	- criar critérios de qualidade de aceite do produto a longo prazo

- pesquisa com usuário
	- testes a/b
	- falar com o usuário final para saber o que ele quer
	- falar com o usuário final saber 
	- quais os desejos
	- o que motiva o usuário a usar se produto
	- quais as necessidades
	- quais tarefas ele deseja realizar
	- quais as principais tarefas que o usuário final deseja fazer no sistema
	- quais são os comportamentos específicos do publico alvo para moldar a plataforma
