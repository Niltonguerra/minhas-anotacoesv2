# Explicação dos tópicos:


## problemas comuns nos monólitos:
- dificuldade em integrar novas funcionalidades
- complicações com novas ferramentas de build
- escalabilidade e trabalho em equipe

## o que é o microfrontend?
- é meio que um microserviços, mas para o frontend
- trás os benefícios do microserviços para o frontend
## qual problema resolve o microfrontend
- fragmentação em pedaços menores e independentes
	- facilita mandar o código
	- ler o código
	- identificar erros
	- e etc
- equipes autônomas e desacopladas
	- facilidade em deploys


## desvantagem
- mais difícil de implementar que um monolito
- coloca uma complexidade maior no projeto
