 ## 7 problemas para serem considerados antes de iniciar a criação do planejamento de um projeto
![[Pasted image 20250412181937.png|1075]]
1. falta de clareza nos objetivos
- cada pessoa que você falar vai achar alguma coisa
	- ex:
		- professor vai ver de uma forma
		- diretor vai ver de outra forma
		- coordenador vai ver de outra forma

2. Scope Creep
- toda vez que você vai falar com alguém a pessoa acha uma coisa diferente

3. Expectativas Irreais
-  as pessoas acham que é mais fácil do que realmente é

4. Recursos Limitados

5. Falha na Comunicação
- o que vou falar, poxa, é não ser claro com o outro ou não perguntar o que o outro quer

7. Atraso nas entregas

8. falta de Transparência
