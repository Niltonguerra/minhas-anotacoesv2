## vantagens:
- estilização fica em um único lugar
	- facilita localizar o local da estilização
- escopo local no componente
	- evita propagação errada de estilização
- facilita a manutenção


## desvantagens:
- Custo de runtime
	- em apps grandes pode deixar mais lento o sistema
- inviabiliza algumas tags semanticas


## exemplo de uso:
comando para instalar:
```
npm install styled-components
```
